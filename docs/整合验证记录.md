# 全仓库整合验证

本次整合将 backend #1、#2、#4、#5、#6、#7 的提交共同纳入主分支；前端另行整合 #6、#7，Agent #3 独立合并。

冲突处理保留禾禾日常聊天、病害分流、真实检索接口和缺素证据约束，同时接入病害资料查询与按问题类型组织的追问回答。“为什么”“什么时候”等短追问在存在诊断上下文时不进入闲聊兜底；“你好”“谢谢”等明确社交表达仍优先处理。病害资料回复保留来源并说明不代表确诊，否定症状不能成为病害命中证据。已有病害资料的部分来源为机构首页，不能据此声称条目已经逐条完成原文核验。

内置静态网页来自 front-end `0835045`，构建环境为 `VITE_USE_MOCKS=false`、`VITE_API_BASE=/api/v1/fe`。保留右侧禾禾、照片本地预览、水分/光照/土壤分析、所有状态下对话及可读候选信息。

验证通过：后端 59 项 Java 测试，爬虫 13 项 Python 测试；前端 45 项测试、类型检查和生产构建；Agent 仓库 15 项 Java 测试及 10 项 Python 测试。未发起付费模型或向量调用。
