# 禾禾日常对话

`POST /api/v1/chat` 优先根据本轮 `question`（其次 `message`、`symptomText`）识别社交意图。问候、自我介绍、功能介绍、感谢、告别、晚安、赞许、致歉、近况、简单安慰、笑话、鼓励和确认使用本地回复，不调用诊断或模型服务。回复仍通过 `meta / token / done` SSE 事件发送，完成状态为 `CHAT`。

可尝试：“你好啊”“禾禾你好”“你是谁”“你能做什么”“谢谢禾禾”“讲个笑话吧”“我好累”“晚安”。标点、空白和英文大小写不影响匹配。回复明确使用“禾禾”身份，功能介绍说明照片当前仅本地预览。

只对完整社交表达匹配，包含农业线索的其他输入继续原诊断流程，例如“你好，番茄叶片发黄怎么办”。上一轮附带的病害症状不会把本轮“谢谢”重新变成病害分析。不认识的日常问题友好请求澄清，不编造百科答案或追问缺素症状。

这是一组可审查的本地意图与回复，不是模型训练或通用聊天模型。可在 `HeheConversation` 中扩充表达及回复，并增加混合症状、问候及上下文测试；不会增加模型费用或爬虫任务。
